# 家膳智选 · 当前可运行版本

## 启动

1. 确认 Windows 的 `MySQL80` 服务已启动。
2. 在项目根目录执行 `powershell -ExecutionPolicy Bypass -File Server/Start-Server.ps1`，保留服务进程。当前配置仅监听本机 `127.0.0.1:8766`。
3. 打开 `Assets/JiaShan/Scenes/JiaShan.unity`，Game 视图选择 `Samsung S10 1080x2280`，点击 Play。
4. 从欢迎页注册账户，按人数逐位填写家庭信息，确认后进入首页。已有账户可以登录。

服务检查地址：`http://127.0.0.1:8766/health`；接口说明：`http://127.0.0.1:8766/docs`。

## 当前边界

AI 菜谱、图片生成、拍照识别和语音暂未接入。首页、收藏等页面显示真实空状态，相关操作给出提示；菜谱、备菜、烹饪等预制体保留设计外观，用于后续接入业务。当前不会把设计稿中的示例菜谱、成员或摄入量当成真实数据。

登录令牌只保存在内存，停止 Unity 或重启接口后需要重新登录。账户密码使用加盐 PBKDF2 哈希保存。接口只用于本机开发，尚未作为公网服务部署。

业务数据保存在电脑上的 MySQL。Unity 通过本机接口访问数据库，不需要互联网，但需要本机数据服务。若后续在手机运行，需要电脑和手机处于同一局域网、调整监听地址与 Unity 的接口地址；手机不能用 `127.0.0.1` 访问电脑。本版本尚未完成 Android 真机连接和打包验证。

## 编辑与维护

- `Assets/JiaShan/Scripts/App`：启动与模块协调。
- `Scripts/Core/UI`：导航、视图和基础图形。
- `Scripts/Features`：注册、家庭、记录控制器。
- `Scripts/Models`：会话和业务数据对象。
- `Scripts/Infrastructure`：本机 HTTP 数据接口。
- `Server`：MySQL 接口、建表脚本、服务启动脚本。
- `Editor/DesignPrefabBuilder.cs`：从 `Configs/Design.json` 重新生成预制体和启动场景。菜单“家膳智选/生成界面与启动场景”会覆盖生成文件，手工调整前先备份。

`Server/.env` 保存本机专用账户配置，已被 Git 忽略；不要提交此文件。`Server/.venv` 为本机环境，同样不提交。Luban 暂不导入，配置规模较小时使用 JSON 即可。

没有预置业务账户或演示记录，请自行注册和填写。不要把 MySQL 的管理账户密码作为 App 注册密码。
