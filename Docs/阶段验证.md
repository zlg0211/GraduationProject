# 第一阶段验证记录

验证环境：Unity 2022.3.62f3c1 / Windows / MySQL 8.0，Game 视图 1080×2280。

## 检查结果

### 页面滑动过渡更新

- 编辑器 `NavigationTransitionProbe` 已验证进入/返回动画的中间值：在时长一半处 OutCubic 完成 87.5%，子页、父页和遮罩都遵循同一曲线。
- 父页平移总量为屏宽 25%，黑色遮罩最大不透明度为 25%，页面 CanvasGroup 透明度保持 1。
- 同级主导航、首次信息填写步骤不播放动画；登录完成和档案完成页向下滑出。
- 普通返回复用父视图，保留页面状态；动画期间重复导航被拦截。
- 真实“我的 → 我的收藏”动画中间帧已渲染核对，前景页面覆盖被压暗的父页面。
- 更新后重新通过注册、两位成员填写、档案修改、返回导航、饮食记录、设置开关、退出与登录读取的完整操作流程。临时测试账户已清理。

### 基础功能

- C# 编译通过。最终运行检查时 Unity Console 无错误或警告。
- 26 个页面预制体生成成功，合计 106 个 Button、21 个 InputField、10 个 Toggle、2 个 Slider，丢失脚本数为 0。
- 渲染检查了全部 26 个页面的原生元素，照片、中文字体、图标路径、圆角、阴影和底部导航正常显示。
- 通过真实 Unity 按钮完成：欢迎 → 注册 → 2 位成员 → 目标与口味 → 家庭确认 → 首页 → 我的 → 成员编辑 → 修改过敏原 → 返回我的 → 饮食记录 → 手动添加 → 汇总显示。
- 设置开关正常切换；退出后重新登录，可以重新读取已保存的饮食记录。
- 直接查询 MySQL，确认 Unity 输入的成员目标、口味、过敏原及饮食记录已落库。
- 接口验证通过：新账户为空档案，家庭写入与读取、饮食写入与读取正常；负数营养值被拒绝。
- 临时验证账户和关联记录已删除，交付时三张业务表为空，没有预置演示数据。
- 本地数据库配置和 Python 虚拟环境已被 Git 忽略。

编辑器联调工具为 `Assets/JiaShan/Editor/UiFlowProbe.cs`，只在手动调用 `Run()` 时执行，不参与手机运行。该工具会创建临时验证账户；再次运行后应根据其 `Username` 清理对应账户，外键会级联清理关联记录。

本阶段未验证 Android 真机与打包，未接入任何 AI 接口。AI 功能的识别准确率、响应速度与费用不在此次验证范围内。
